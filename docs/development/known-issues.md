# 已知问题与暂缓项

## 当前已知限制

- 同步 LLM 调用可能使上传请求等待数十秒。
- 没有登录与权限模块，操作者身份只是手工声明。
- 邮件和证据摘录明文保存，不适合生产敏感数据。
- 邮件引用区识别是启发式处理，无法保证所有客户端格式均准确。
- 真实模型具有非确定性，live LLM 指标不作为常规 CI 门禁。
- 只支持三个演示领域，真实业务上线前需更新字典。
- 只支持本地 Mock Gateway，不代表真实 UTP 兼容性。
- 提交成功后不能修改、撤销或更新外部计划。

## 暂缓能力

- 用户、租户、RBAC、SSO。
- Celery、Redis、异步队列和自动重试。
- `.msg`、粘贴文本、附件正文和批量导入。
- 真实测试管理平台连接器。
- 字典和规则管理后台。
- 静态数据加密、密钥轮换、备份和灾备。
- 计划替代、克隆、撤销和外部更新。

新增问题时记录发现日期、影响、临时处理和计划解决阶段。
