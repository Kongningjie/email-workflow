# 实施计划

## 阶段 0：契约与工程基线

- 初始化 Python、前端和 Docker Compose。
- 建立配置、日志、错误结构和质量门禁。
- 创建初始 Alembic migration。
- 落地领域、值域、规则、Prompt 和映射 YAML。
- 完成八封黄金 `.eml` Fixtures。

完成标准：应用、Gateway、数据库和前端空壳可启动，基础检查通过。

## 阶段 1：安全邮件导入与证据

- 上传校验、SHA-256 去重、MIME 解析。
- HTML 清洗、引用分区和噪声清理。
- EvidenceSegment 切片、哈希和保留期。

完成标准：黄金样例和恶意输入测试通过。

## 阶段 2：LLM 提取与草稿

- Pydantic 提取契约、FakeExtractor 和 LLMExtractor。
- Prompt 版本化、注入边界、领域／值域映射。
- 证据重建、失败降级和版本 1。

完成标准：默认离线测试通过，可显式运行 live LLM。

## 阶段 3：规则、版本与 Review

- 规则引擎、不可变版本、RFC 8785 和乐观并发。
- 送审、退回、Warning 确认、批准及对应 API。

完成标准：状态机和版本不变量由数据库与服务测试证明。

## 阶段 4：Mock Gateway 与提交

- 平台 DTO、映射、validate、预览和确认令牌。
- HMAC、幂等提交、Mock 场景、unknown 对账和重试。

完成标准：成功、重复、4xx、5xx、超时和对账端到端测试通过。

## 阶段 5：现代简约前端

- 五个冻结页面及嵌套计划编辑。
- 证据、规则、Review、预览和提交结果。
- 响应式、可访问性和错误反馈。

完成标准：组件测试、构建和主链路浏览器测试通过。

## 阶段 6：验收与交付

- 执行全部质量门禁和八封确定性黄金样例。
- 人工触发 live LLM 并产出指标报告。
- 检查保留期、日志脱敏和文档一致性。
- 更新开发日志和已知问题。
