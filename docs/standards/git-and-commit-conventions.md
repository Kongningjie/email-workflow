# Git 与提交规范

## 分支

- 功能分支默认使用 `codex/` 前缀。
- 一个分支只处理一个清晰主题。
- 不混入无关 IDE、数据文件或本地配置。

## Commit

```text
feat: 实现邮件证据切片
fix: 修复重复提交幂等判断
test: 增加提示注入黄金样例
docs: 更新冻结状态机
refactor: 提取平台连接器协议
chore: 更新锁文件
```

- Commit 保持可审查、可回滚。
- 说明业务原因，不只描述文件变化。
- 不提交密钥、真实邮件、数据库卷、构建产物或日志。

## 冻结方案变更

- 改变范围、领域模型、状态机、外部契约、安全边界或指标前必须新增 ADR。
- ADR 批准后同步更新 `frozen/`、测试和实施计划。
- 不允许只改代码、不改冻结文档。
