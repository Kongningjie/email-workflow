# 06. 确定性规则引擎

规则引擎独立于 LLM、Workflow 和前端。规则代码使用 Python，规则元数据和启用状态使用版本化 YAML。前端和 LLM 均不能删除结果或降低严重级别。

每条结果包含 `rule_id`、`rule_version`、`field_path`、`severity`、`message`、`suggestion`。

## 严重级别

- `blocking`：阻止送审、批准和提交，不可人工豁免。
- `warning`：允许继续，但批准时必须逐条确认。
- `info`：仅展示。

Warning 确认绑定版本、内容哈希、规则 ID／版本、操作者声明和时间。修改后失效。提交前重新校验，新的 Blocking 或未确认 Warning 均阻止提交。

## 首版 Blocking

- 计划必填字段缺失；计划日期顺序错误；没有领域明细。
- 领域未知、停用或编码缺失。
- 负责人或工号缺失；工号不匹配 `^[0-9]{9}$`。
- 领域日期非法或超出计划日期；同一计划重复领域。
- 领域没有需求或测试用例。
- 用例标题、目标、步骤、预期结果或优先级缺失。
- 用例 `domain_key` 与父领域不一致。
- 事实字段缺少合法证据。
- 证据不存在、越界或哈希不符。
- 存在未解决的必填字段或未知领域。
- 值域不存在或已停用。
- 平台必填字段缺失、超过硬限制或包含禁止字段。

## 首版 Warning

- 标准化后完全重复的用例。
- 使用领域字典默认负责人（首版配置不会触发）。
- 测试环境、风险或依赖为空。
- 文本接近平台上限。
- 某需求只有模型建议用例，没有直接来源用例。
- 关键事实只存在于历史引用正文。
- 无法可靠分离当前正文与引用区。
- 检测到明显提示注入文本。

## 首版 Info

- 字段使用确定性继承值。
- 用例来源为 `model_suggestion`。
- 可选字段缺失。
- 用例标题或描述有非阻断优化建议。

测试类型、阶段、优先级和领域均从版本化 YAML 加载，不使用写死的 Python Enum。字段长度属于规则／映射配置细节；超限不得静默截断。
